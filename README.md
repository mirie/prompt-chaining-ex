# prompt-chaining-ex

An empty Python project managed with [uv](https://docs.astral.sh/uv/).

Requires Python 3.12 or newer. No application code yet.

Includes LangChain, LangChain Community, LangChain OpenAI, and LangGraph.

## Get started

```sh
uv sync
uv run python -c "print('Python environment ready')"
```

## Add code and dependencies

Create a Python file, then run it with `uv run your_file.py`.
Add dependencies with `uv add package-name`; commit both `pyproject.toml` and
`uv.lock` when dependencies change.
